# goit-advancedjs-hw-01

**Module: Advanced JavaScript and TypeScript**

## Description

DOM manipulation fundamentals — building an image gallery with a lightbox and a persistent feedback form.

## Tasks

- **Image Gallery** — renders a card grid from a data array; clicking a card opens a modal overlay with a larger image and caption.
- **Feedback Form** — a contact form that saves input to `sessionStorage` while the user types and clears it on successful submission.

## Stack

- Vanilla JavaScript (ES6+)
- Vite
- HTML / CSS
